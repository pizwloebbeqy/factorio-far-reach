## Overview

Far Reach extends the player character's interaction range in Factorio for both building and mining, allowing players to place entities, insert items, and mine resources from greater distances. Configurable reach values make it suitable for convenience use or for accessibility purposes in large or complex factory areas.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Far Reach** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Extended Build Range** | Place and remove entities from significantly greater distances |
| **Extended Mine Range** | Mine resources and pick up items from further away |
| **Configurable Values** | Adjust build and mine reach distances independently in mod settings |
| **Map Interaction** | Interact with map objects without needing to walk to them |
